# Forge Workshop: Adventure duel interface

The first implementation improves the landscape Adventure duel prompt:

- A separate status row shows the turn number, turn owner, localized phase,
  and the player with priority.
- The engine's existing action labels and enabled states appear together in
  larger buttons. The reversed-button preference remains supported.
- A Card Preview button opens Forge's existing inspector when the current
  prompt or selection supplies a card.
- Long prompts retain their tap-to-magnify behavior. Classic and portrait
  layouts retain their existing compact prompt.

Rules, AI, card definitions, campaign progression, and save formats remain
upstream implementations. UI state refreshes through existing controller
notifications rather than a new gameplay loop.

## Build and play

Requirements: JDK 17+, Maven 3.8.1+, Python 3, and Git. Set `FORGE_JAVA_HOME`
and `FORGE_MAVEN` to override the local tool locations.

```sh
python3 scripts/build-workshop.py
sh scripts/play-workshop.sh
```

The build script mirrors tracked build inputs into a temporary directory on
the local disk, runs Maven's existing tests and Checkstyle, and copies the
packaged Adventure JAR to `.dev/dist/forge-workshop.jar`. This avoids macOS
AppleDouble files being treated as Java sources or test classes on external
FAT volumes. Temporary build folders can be regenerated by the build script.

On macOS, create a native application with its own bundled Java runtime:

```sh
python3 scripts/package-workshop-macos.py
```

Launch `.dev/apps/Forge Workshop.app`. Keep the source checkout available:
the local launcher reads Adventure resources from `forge-gui/res`.
Set `FORGE_WORKSHOP_APPS` to a local application folder when packaging on an
external FAT volume. Close and move aside an existing Workshop app before
repackaging; the script refuses to overwrite it.

## Data isolation

Workshop saves and preferences use `.dev/profile`; downloads other than card
pictures use `.dev/cache`. Existing `/Volumes/Seagate/Forge/card-pictures`
storage is shared when available. Set `FORGE_CARD_PICTURES` before creating
the profile to use another existing picture folder.

The generated `forge-gui/forge.profile.properties` is ignored by Git. Launch
scripts check that it selects the isolated Workshop profile before starting.
The normal installed Forge application's saves are not used for playtesting.

## Remaining work

This is the first interface increment. Targeting, stack presentation, combat
connections, deck building, shops, and overworld artwork are later milestones.
Commander and dense multiplayer layouts need separate interactive verification.

## Validation of this increment

- JDK 17 Maven package succeeds for the Adventure application and dependencies.
- Existing Checkstyle checks pass; all 11 existing tests pass without skips.
- On macOS, the native launcher starts Adventure from outside the checkout.
- An isolated Adventure character reaches the overworld and enters a duel.
  Keep, priority pass, End Turn, turn/phase updates, card inspection during
  mana payment, and Cancel were checked with actual mouse input.
- Classic, portrait, reversed controls, and multiplayer layouts have not yet
  received interactive regression testing.
